# Instructor-led workshop

## What we are going to learn
Install tools, understand GitHub, synchronize a team's repository tree, schedule a refresh and create an Artifact. No software prerequisites beyond the ability to install.

## Who I am
Blake: classroom teaching and curriculum development, AI tutoring systems since 2023, enterprise AI engineering and technical project management. Use approved personal examples.

## Check-in
Show an actual snapshot. Explain what make sync does, which system is authoritative, when the dashboard was refreshed, and how to verify a count. Ask experienced participants: Where could we go from here? How would you extend it? What advice can you share from experience? Identify willing peer tutors without imposing teaching duties.

## Differentiated practice
**Extension:** release participants ready to work independently. Past learners built Excel dashboards, Claude Artifacts and HTML pages. Choose a useful decision or view, build it in any format, verify one metric and show refresh.
 
**Instructor-supported:** work one-on-one or in small groups on the precise blocker (installation, account setup, authentication, repo selection, interpreting JSON, schedule or Artifact prompts). Provide scaffolding and ask learners to retry independently. Use sample data if access is blocked. 

## Closure
Invite participants to demonstrate different outputs. Highlight the shared data foundation and how the presentation is customized to their work.
