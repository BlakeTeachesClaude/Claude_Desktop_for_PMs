GitHub in five concepts

  • Organization: the container for a team’s repositories.
  • Repository: code, files and history.
  • Issue: a work item; pull request: a proposed change.
  • Project: a cross-repository planning view with custom fields.
  • GitHub CLI (gh): a command-line interface to GitHub.

In JiraIn GitHub
ProjectRepository holds the work. A GitHub Project is a planning view across repositories.

Story / Task / BugIssue. Use labels or issue types to tell them apart.
SprintMilestone, or an iteration field in a Project.
Board and workflow statusProject Status field. The issue itself is only Open or Closed.
