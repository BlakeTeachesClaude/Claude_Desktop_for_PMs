# Fictional engineering team

Four planned public repos: demo-storefront, demo-orders-api, demo-platform-infra and demo-product-docs. See seed.json for the issues and PR descriptions. The sample snapshot contains 12 issues, four PRs and 16 project items.

An organization owner can provision these using `gh repo create BlakeTeachesClaude/NAME --public --clone`, initialize a README, create three issues and a branch with a PR, then create a public GitHub Project and add each record. Use gh CLI or the web UI. Do not use real company data. The connected GitHub tool cannot create repos or projects, so no live demo repos have been created yet.
